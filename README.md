# Beeskilled Internship – Week 3

This repository contains my Week 3 Python programming tasks completed as part of my internship at Beeskilled.

## 📌 Tasks Completed

### 1. Bank Account Class
A Python program that demonstrates a bank account using a class.

It focuses on:
- Creating a bank account
- Managing account details
- Depositing money
- Withdrawing money
- Working with class objects

### 2. Billing System
A simple billing system developed in Python.

It demonstrates:
- Product details
- Price calculation
- Quantity handling
- Total bill calculation
- Object-oriented programming concepts

### 3. Calculator Class
A calculator implemented using a Python class.

It performs basic mathematical operations such as:
- Addition
- Subtraction
- Multiplication
- Division

### 4. Library Management System
A library management system developed using Python and Object-Oriented Programming.

It demonstrates concepts such as:
- Classes and objects
- Book management
- Adding and managing books
- Borrowing and returning books
- Basic library operations
